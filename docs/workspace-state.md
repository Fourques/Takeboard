# 工作区状态与生成编排边界

这次收尾针对两项确定的债务：App 中分散的编辑选择状态，以及 App 中的生成参数、设备发现和任务编排。不是对整个仓库作“零缺陷”的承诺，也不以文件长度作为完成标准。

## 状态归属

| 模块 | 唯一负责的内容 | 不负责的内容 |
| --- | --- | --- |
| `use-project-document.ts` | 项目快照与版本、显式导航、拒绝旧版本/跨项目响应 | 编辑选择、生成任务 |
| `editor-selection.ts` / `use-editor-selection.ts` | 当前节点/连线/空白、镜头上下文、检查器可见性、右键菜单锚点 | 项目修改、独立保存第二份右键操作对象 |
| `use-generation-environment.ts` | Worker 状态、Workflow 目录、手动发现/启动、连接切换后的请求失效 | 重新读取项目目录、迁移项目 |
| `use-generation-draft.ts` | 同一项目内按镜头与工作流隔离的草稿、输入映射、工作流绑定、默认偏好 | 任务生命周期、持久化未提交提示词 |
| `generation-readiness.ts` | 首次提交和重试共用的前端参数检查 | 代替服务端权限、依赖和执行校验 |
| `use-generation-session.ts` | 有序提交、等待确认、重试、明确取消及视图生命周期 | 编辑选择、复制项目运行列表作为第二个数据源 |
| `use-run-recovery.ts` | 新任务及重开的任务共用的运行状态订阅 | 拥有后台任务、关闭页面时取消生成 |
| `App.tsx` | 页面组合、项目生命周期 UI、画布命令入口及展示适配 | 直接维护选择/生成状态，直接提交、取消或轮询生成服务 |

`use-shot-generation.ts` 只组合生成领域的三个模块并公开视图数据与用户操作，不另存一套状态。没有引入全局状态管理框架。

## 选择行为

- 点击镜头，一次转换同时更新目标、镜头上下文和检查器。
- 点击素材或笔记，保留当前镜头上下文，便于连接素材、追加文本；点击空白则清空上下文。
- 选连线时清空节点与镜头目标、关闭检查器；改选节点时不保留旧连线身份。
- 右键菜单只保存屏幕与画布坐标，操作目标从同一选择状态派生。节点/连线删除后菜单同步关闭，不保留失效对象。
- 后台快照更新只校正已失效的选择，不自动挑另一个镜头。生成和工作流绑定响应没有“指定首选镜头”接口，不能抢回用户的选择。
- 采用结果可收起画布内编辑控件，同时保留右侧镜头详情；这一行为是显式转换，不是临时把几个字段分别设空。

## 生成与恢复行为

1. 草稿按项目、镜头、工作流标识隔离。同一项目内切换镜头会保留已编辑草稿；它们是当前标签页的临时输入，关闭页面不保证保留未提交的提示词。已经提交的参数从 Run 记录恢复。
2. 首尾帧与参考素材由项目连线推导。App 不再在连接、断开之后手动修改另一份输入 ID；生成图片/视频和普通素材共用来源解析。
3. 参数偏好只保存实际编辑过的、属于当前工作流的有效数字，不能把上个工作流的设置写到新工作流名下。
4. 提交时固定本次参数和批次，按顺序发送，保留请求返回的版本。网络失败不自动重发可能已经执行的任务。重试依据原 Run 的工作流、参数和输入，再经过同一前端检查及服务端校验。
5. 提交完成后交给已有运行订阅。已删除提交函数中的独立轮询循环，以及重复的传输进度轮询/客户端封装；运行接口已返回执行或传输的真实进度。
6. 单次运行显示它提供的真实进度；批次显示已保存的候选数量，不混算采样与传输百分比。同一候选重试不会重复计数。
7. 明确取消会等待正在提交的请求返回，再读取当前项目核对该镜头的非终态 Run。不能带上以前提交的其它镜头。停止无法确认时保留错误或待核对提示，不声称已停止。
8. 离开项目只解除视图订阅、停止继续提交尚未发出的候选，不取消服务端已接受的任务。明确发出的取消请求仍针对原项目执行；迟到响应不会覆盖新的项目或选择。

## 完成检查

- App 中已无选择、检查器、右键目标、生成草稿、候选数量、生成生命周期或 Worker/Workflow 的状态声明。
- App 中已无直接生成、取消、运行/传输轮询、工作流发现或 Worker 启动请求。
- 选择转换有纯函数测试；运行来源、参数检查、取消范围和批次统计有独立测试。
- 浏览器专项验收覆盖跨工作流草稿隔离、取消等待任务身份、停止剩余候选提交、跨镜头取消及迟到响应不抢选择；既有创建、输入、连线、删除、采用、重开和权限流程保留。
- 源码边界回归检查用于阻止上述状态和服务调用被直接加回 App；它只是防回归检查，不代替行为测试。

两项指定债务按上述标准关闭。App 仍包含页面 JSX 和项目操作 UI，这些不是选择或生成状态的第二个所有者。后续是否再拆展示组件应依据独立复用和交互需求，而不是把行数清零。
