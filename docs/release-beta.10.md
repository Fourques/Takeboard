# v0.2.0-beta.10 · Mac M 系列调试版

包含 beta.9 候选的模板库、推荐配置和镜头详情升级，并修复离线错误提示遮挡生成按钮的问题。通知移至上方，保留处理入口及关闭操作，并限制展开高度。

仅提供 Apple Silicon（M 系列）DMG。该版本替代未公开的 beta.9 候选；beta.8 仍可用于回退。模型权重、ComfyUI 和第三方节点不随包安装。

安装前保存编辑、备份重要项目并等待本机生成结束；退出 TakeBoard 后将新版拖入「应用程序」替换旧应用，不要删除项目目录或应用数据。

本版仍为临时签名调试包，没有 Apple 公证。最终 DMG 需要通过包内运行验证；不宣称本轮完成 Mac 人工交互或 GPU 生成质量验收。

已知其他平台验证缺口：Linux 原生窗口验收仍在等待已迁入设置的旧远程项目独立窗口，需另行更新验收。此次不发布 Linux 安装包。
