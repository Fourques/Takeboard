# TakeBoard 产品定位与表达原则

更新：2026-09-30。此页替代早期立项假设；当时的研究与方案保留在 Git 历史中。当前能力以[README](../README.md)、[下载版本](downloads.md)及对应实现为准。

## 核心定位

**基于 ComfyUI 的开源 AI 创作画布。**

用户在同一工作区选择模型、连接素材、编写提示词，生成图片与视频，再用结果继续创作。TakeBoard 将已有工作流转为创作者可操作的画布工具，保留对模型、生成设备与项目位置的选择。

对外主张：**把 AI 图片与视频创作，放进同一张画布。**

English: **One canvas for AI image and video creation.**

## 核心用户与任务

- 希望用可视化画布探索图片、视频和多个版本的创作者。
- 已有 ComfyUI 环境，希望日常创作不必反复操作底层节点图的用户。
- 从笔记本连接自己 GPU 工作站或服务器的用户。

产品可以逐渐降低配置门槛，但当前安装包不包含模型和 ComfyUI，不能把“可直接安装桌面应用”说成“无需准备环境即可生成”。

核心任务是：选择创作方式 → 准备参考素材 → 设置生成 → 查看结果 → 将结果用于下一步。素材管理、参数记录、任务状态与保存恢复服务于这条流程。

## 三项核心价值

1. **统一创作画布**：素材、文本、生成节点与结果在同一工作区，可以连接输入、并排探索和继续生成。
2. **可选择的模型与工作流**：按创作任务使用可用工作流，推荐模板按需添加，也能导入自己的工作流；需要深度编辑时返回 ComfyUI。
3. **开源与自有环境**：连接本机或远程生成服务，自选项目保存位置，不依赖官方云端订阅。

这些是产品提供的价值，不宣称是行业独占功能。公开宣传不以其他产品名称、“平替”或未经验证的优劣比较表达自身价值。

## 产品边界

- 画布表达创作对象与输入关系；不是底层 ComfyUI 节点图，也不自动执行整张画布。
- 模型能力、生成质量与性能由实际工作流和设备决定；连线不能增加模型原本不具备的能力。
- 账号、远程项目、门户与扩展按需使用，不是开始创作的前置步骤。
- 成本、批量审片和粗剪是可选能力，不定义整个产品，也不构成完整剪辑器或商业计费平台。
- 不将未来的 Agent 创作、自动成片、云端账单或任意插件执行描述为当前能力。

## 对外信息顺序

首屏说明是什么、可完成什么创作以及下载入口。紧接着展示实际创作方式、工作流选择和本机/远程使用。素材管理和生成记录出现在相应操作中，不占用主标题。

首次试用面向一个能完成的创作任务，不把诊断、审批、成本或版本考古安排成新用户必经步骤。平台、主要界面语言、依赖、Beta 与系统打开限制应在下载和安装环节清楚说明。

实现细节、证据哈希、权限结构、状态机与完整验收矩阵保留在技术文档。模拟素材需要标记，未完成的功能不能通过文案暗示已经实现。

## 下一阶段判断标准

- 新用户能否理解“这是用来创作的画布”，而非素材管理器或另一张 ComfyUI 节点图。
- 已有 ComfyUI 的用户能否找到一个可用工作流并完成第一次生成。
- 从一个结果继续下一步创作是否顺畅，是否出现模型、输入或状态上的理解障碍。
- 真实 Demo 能否直接展示上述流程与结果。
- 文案是否准确对应可下载版本，英文入口是否匹配当前界面语言。

不以宣传数量或功能数量替代这些用户结果。后续优先级见[路线图](roadmap.md)，本轮修改依据见[表达 Review](product-expression-review-2026-09-30.md)。
