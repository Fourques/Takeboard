# 生成设备与项目位置

TakeBoard 中有两个独立选择：**项目保存在哪里**，以及 **ComfyUI 在哪里运行**。连接另一台电脑生成，不会移动项目。

本文描述本次源码改动；桌面用户需安装包含这些改动的新安装包，并非打开旧版 App 后自动出现。

## 本机项目，远程生成

1. 在本机打开 TakeBoard，创建项目时选择项目文件夹。默认位置可在“设置”中修改，只影响以后创建的项目。
2. 打开“设置 → 设备连接 → 添加设备”。顶栏仅提供已保存设备的快捷切换，不重复放置配置表单。
3. 选择 SSH，填写 `user@服务器IP` 或系统中配置的 SSH 名称，以及**服务器的 ComfyUI 端口**（通常为 `8188`）。显示名称可以自定义。
4. 连接成功后使用该服务的模型与工作流。生成所需素材会上传副本，生成结果下载到项目文件夹。

设备列表区分“使用中、可连接、未连接、离线、已停用”。未建立的 SSH 连接不会被假定为在线；没有响应的默认地址不显示成一台可用的本机设备。已有回环配置显示真实地址，不据此推断 GPU 所属电脑。连接失败保留原来的选择。服务启停在同一设置页内，仍需通过安全预检；调度用途、费用及素材发送权限保留在折叠的“调度偏好”中。

SSH 隧道由 TakeBoard 后台服务独立维护，不需要 VS Code 或单独开着终端。仅绑定当前项目设备的回环地址，自动选择空闲端口；端口不作为服务器身份保存，也不会抢占或结束其他程序。退出 TakeBoard 后释放自建连接，不会停止远端 ComfyUI。

首次 SSH 授权仍需要配置系统 SSH 密钥并核实服务器指纹。TakeBoard 不保存 SSH 密码、不跳过主机身份检查；账号登录也不替代 SSH 授权。SSH 用户、SSH 端口和跳板机沿用系统 SSH 配置；界面里的端口不是 SSH 端口。Windows 需具备系统 OpenSSH 客户端。

浏览器版由运行 TakeBoard 后台服务的设备建立 SSH，不会读取浏览器所在电脑的 SSH 私钥。若后台服务由其他窗口复用，关闭一个窗口不会停止共享后台或其他用户的传输。

也可填写 ComfyUI 的 HTTPS 地址。未加密的局域网 HTTP 服务请使用 SSH；HTTP 回环地址可以直接连接。回环地址只说明接口在哪里，不证明 GPU 在此电脑上——它也可能是其他工具转发的远程服务。

此模式不需要远端 TakeBoard。ComfyUI、模型和自定义节点须在生成设备上准备好。连接不等于启动授权：当前独立连接只管理隧道，不会盲目运行远程命令、安装软件、代启或停止无法核实归属的 ComfyUI。

## 文件流与恢复

```text
用户选择的项目文件夹
  assets/   原始导入素材（生成时上传副本）
  renders/  按镜头与任务归档的生成结果
     ↑
  ComfyUI 生成 → 按实际输出记录下载 → 完整写入 → 项目记录完成
```

- 工作流使用执行端上传接口返回的素材标识，不把本机绝对路径传给远端。
- 结果按工作流实际返回的文件名、子目录及类型读取，不要求自定义工作流使用固定输出目录。
- 下载流式写入临时文件；检查长度、计算 SHA-256、刷新文件后再发布正式文件。不将下载了一半的文件显示为完成。
- 传输百分比来自实际字节数。服务没有给出可靠的文件长度时，只显示已接收数据量，不推算百分比。
- 失败时保留任务编号和输出描述；恢复连接/磁盘空间后自动重试下载，不再提交生成。失败重试间隔为 30 秒。当前是完整文件重试，**不是断点续传**。
- 后台收集不依赖浏览器页面。关闭本机 App 会停止其下载与 SSH；下次启动重新连接并继续核对待完成任务。远端仍需保留生成文件；若文件已删除，TakeBoard 无法凭记录恢复它。
- 自定义工作流应避免覆盖同名结果；已被远端删除或覆盖的文件无法凭任务记录找回。
- 大文件传输不长期占用项目编辑锁。取消或删除项目会先停止对应本地下载；已经生成的远端原文件仍保留。
- 完成归档不会自动删除 ComfyUI 原文件或历史。清理远端磁盘由其所有者管理；没有跨设备通用的安全文件删除 API。
- 有生成或待下载任务时阻止切换生成设备；断线后可以恢复同一连接，不会悄悄把旧任务指向默认 GPU。

## 项目也需要放在服务器时

使用桌面应用的“远程项目”入口连接**远程 TakeBoard**。远端设备需先安装 TakeBoard；有明确授权时，连接器可以启动它已安装的后台服务，不是启动编辑器或依赖源码环境。

在远程项目窗口创建项目时，选择的是服务器允许的项目文件夹。素材、项目数据与归档结果都保存在该服务器；点击下载将所需图片/视频保存副本到当前电脑。本机“在文件夹中显示”不会错误地尝试打开服务器路径。

## 安装包与兼容边界

新版桌面入口会显示操作失败或未响应原因；原生文件夹选择与窗口桥接的修复需要包含这些代码的新安装包。仅更新服务器源码不会修改已经安装的旧版 App。浏览器版可管理生成连接及服务器允许的保存位置，但不能调用客户端原生文件选择器。

同账号发现设备仍属于已授权的 Portal 配对流程，不因邮箱相同自动获得远程访问权限。连接记录属于运行当前 TakeBoard 服务的设备，包含名称和地址，不含 SSH 私钥。
