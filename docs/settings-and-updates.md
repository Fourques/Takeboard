# 设置与更新

适用于 `0.2.0-beta.3` 及后续版本。旧 `0.2.0-beta.2` App 没有这些新入口，需先手动升级。

## 设置入口与归属

首页右上角“工作区选项 → 设置”，画布顶栏“设置”。窗口可以滚动，支持窄屏与 Escape 关闭，不修改原来的三维首页。

| 设置 | 生效位置 | 是否影响已有项目 |
| --- | --- | --- |
| 主题、显示大小、首页三维效果 | 当前浏览器/WebView；非敏感外观偏好可跨同一主机的端口保存 | 否，不改变媒体或生成分辨率 |
| 默认项目位置 | 当前连接的 TakeBoard 设备 | 否，仅影响新建项目 |
| 更新频道、启动提醒、跳过版本 | 当前电脑的原生 App 配置目录 | 否，不影响远程服务 |

显示偏好不是账号云同步。禁用浏览器存储仍可使用当前会话；若同时禁用 Cookie 与本地存储，不能保证关闭后保留外观。ComfyUI 启停仍在服务面板，任务、存储与诊断仍在制作进度，备份恢复仍在账号管理；不复制多套互相冲突的控制项。

没有硬件图形加速、远程桌面或设备负载较高时，三维首页的响应可能变慢。可在“显示 → 首页三维效果”选择“节能”，使用静态封面；它不降低素材或生成分辨率，偏好也会保留。

## 默认项目位置

1. 确认设置里显示的设备名或地址。
2. 在“项目与存储”选择设备上的文件夹，点击“保存默认位置”。本机桌面使用系统选择器，远程选择的是服务器文件夹。
3. 新建项目默认使用该位置，也可单次选择其他位置，不会修改默认设置。

设备本机访问者和管理员可修改；普通成员只能继承默认位置，不能浏览任意磁盘目录。默认值属于设备，影响所有获准创建项目的用户，不是假装账号私有的浏览器记录。两个窗口同时保存时，后提交者会收到冲突提示，需重新打开设置，不覆盖其他人的修改。

目录离线或权限不足会明确失败，不在其他地方建立替代项目。可在设置中重新选择，或“恢复内置位置”；恢复默认不删除或移动外部项目。项目包导入/实例恢复沿用既有自包含恢复位置，不用默认新项目位置覆盖原文件。

服务的账号数据库、索引与系统配置目录只读展示，本轮不提供迁移整个实例数据目录的按钮。项目默认值保存在实例目录 `.system/device-settings.json`；允许的根目录在 `.system/project-storage-roots.json`。完整项目包/实例备份恢复不把这些机器路径设置复制到另一台设备，跨设备恢复后应重新设置默认位置。

## 更新提醒

原生菜单“更新 → 检查更新”，或网页设置中的“检查更新与提醒设置”，打开的是本机可信的桌面窗口，不是远程网页的安装权限。

- 启动约 15 秒后在后台检查一次；新版本通过应用菜单与已打开页面的设置标识提示，不弹窗打断创作。可以关闭启动检查。
- 手动检查可随时执行，显示当前 **App** 的实际版本、系统和架构；不拿远程服务的版本冒充客户端版本。
- 测试版安装默认包含稳定版与测试版，正式版安装默认只看稳定版。切换频道不会降级。
- 可跳过一个版本的启动提醒，也可恢复。手动检查仍显示被跳过的新版本。
- 只匹配官方仓库对应系统/架构的 DMG、EXE、DEB；缺少安装包时明确说明，不推荐其他 CPU 文件。Linux DEB 适用于 Debian/Ubuntu，不代表所有发行版兼容。
- 下载由用户点击后在系统浏览器打开。等待本机任务结束、关闭旧 App 后再安装，重要项目先备份。关闭更新窗口即可稍后处理。
- 断网、GitHub 限流或响应异常显示检查失败，不说“已经最新”。请求限时 12 秒、响应限 4 MiB，不执行发布说明中的 HTML，也不下载或执行脚本。

检查访问官方 GitHub Releases API（最近最多 100 条发布），不上传账号、素材、设备名或项目数据；GitHub 会收到连接的 IP。偏好保存在原生 `app_config_dir/update-preferences.json`，不依赖本机服务的随机端口，不使用远程 TakeBoard 的配置。

## 后续应用内安装

当前只有检查与下载提醒，没有静默安装、安装进度或自动重启。完整应用内安装仍需独立完成：签名更新产物与安全保管私钥、发布更新索引、更新前任务/备份/迁移检查，以及各系统安装回归。更新包签名不等于 Apple notarization 或 Windows 代码签名；当前预览包尚未解决系统信任提示。

## 验证边界

- Windows、macOS、Linux 的完整质量门禁 `pnpm verify`、32 条功能浏览器回归，以及独立的 500 节点画布性能检查。
- 六种原生安装包构建；从挂载的 DMG 或已安装的 EXE/DEB 运行真正打包的 Node/服务，验证更新偏好、默认项目位置和登录状态跨进程重启保持、安全释放服务端口。
- 实际读取 GitHub 公开发布，核对六个平台/架构的安装包匹配。更新窗口 DOM 测试使用明确标注的 IPC 替身，不等于 Mac/Windows 原生更新窗口的人工交互验收。
- 平台安装器构建及包内运行时检查结果见对应版本的 [Actions 记录](https://github.com/Fourques/Takeboard/actions/workflows/portable-bundles.yml)；不将这些检查说成原生窗口交互或全部 GPU 工作流的验收。
- 没有新增 GPU 兼容性证明，也未改变原有上游 Linux 依赖告警的处理边界。
