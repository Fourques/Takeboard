# 资产身份与工作区导航整理

本轮只调整资产浏览、结果定位及相邻详情界面，不删除真实素材、镜头、生成历史或扩展能力。

## 产品规则

- 资产是项目中的媒体文件；画布节点是其使用位置；生成结果同时保留所属镜头与运行参数。定位不应创建另一份节点。
- 资产库识别独立素材节点、镜头当前显示的结果、人物/场景引用，以及镜头内的历史结果。卡片区分“画布中”和“镜头结果”；双击定位前者，或打开后者的对应结果。
- 没有画布位置的素材才执行添加。结果详情中的“加入画布”和拖入操作仍表达主动建立独立素材节点，不被历史结果定位吞掉。
- 同名文件使用可区分的显示编号；原始文件路径、保存的素材 ID 和提示词不做批量改写。引用跳转优先使用已保存的身份，不能确定对应关系时不猜测同名文件。
- 默认导航不再保留独立镜头总览。镜头排序、粗剪和批量审片从启用后的扩展卡片进入；单镜头采用、结果历史和素材管理不需要扩展。
- 工作流库入口与模型标题同行；H3 参考图精度直接采用普通参数控件；删除画布上的重复场景编号和标题。
- 登录弹窗采用双栏布局，名称占位为 `Your name`。正常桌面窗口完整呈现；极小窗口仍允许滚动，避免裁掉表单和错误反馈。

## 验证

- `pnpm verify` 通过：代码规范、类型、构建、单元/集成测试、脚本与现有安全边界检查。
- 66 项非 GPU 浏览器回归通过，无重试，含权限、资产库、项目导入导出、撤销重做、模板选择、视频播放和扩展编排。
- 新的资产定位测试使用浏览器录制的真实 WebM 文件和明确标记的完成结果测试数据：从移开后的画布定位视频，重复进入不同结果，校验选中种子，点击改名之前保存的 `@` 引用，确认节点和生成记录均未增加或改写。
- 登录表单在 1440×900、1000×700、920×620 下无内部滚动；个人资料在 1280×720、900×620 下完整显示保存按钮。另保留小窗口、外部关闭及键盘焦点检查。
- 500 节点检查：本次环境加载 456ms，帧间隔 P95 为 17.0ms。不是所有设备的性能保证。
- 截图检查修正了旧的全局 `span` 样式对资产卡片状态文字的覆盖；状态和基础尺寸信息不再缩成 7px。
- H3 补验确认参考图精度无需展开即可在两个选项间切换；统一了下拉框及视频原声复选框的尺寸。收尾样式修改后，另跑 4 项创作全流程、账号布局与无障碍回归，全部通过。

完整回归的第一次运行因浏览器连接中断而未完成，未计为通过；只清理对应测试服务后，使用新的隔离目录完成上述 66 项验证。另修正两项遗留测试中写死的旧发布版本，改为与 package.json 核对。

本轮不将测试结果数据视为真实 GPU 生成验证，没有执行新的 GPU 任务，也没有构建或发布新的 Mac 安装包。已安装的 beta.12 不会自动包含这些尚未发布的改动。
