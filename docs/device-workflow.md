# 此电脑与远程设备

适用范围：当前开发版（Unreleased）。已发布的 `0.2.0-beta.2` 安装包不包含本页新增的设备标识、保存位置和远程启动功能；需要安装包含这些改动的新构建。这里不代表已发布了新安装包。

## 一套流程，不区分电脑品牌

1. 打开 TakeBoard，使用此电脑，或通过“连接 → 连接设备”选择远程 **TakeBoard**。
2. 连接后，顶栏显示设备名称或 SSH 地址；点击可查看实际地址、实例标识和项目文件夹。
3. 新建项目，填写名称并选择该设备上的保存位置。
4. 导入素材、连接镜头和工作流，检查这台 TakeBoard 所连接的 ComfyUI 后生成。
5. 在资产库选择“下载到当前电脑”，保存原文件副本。

TakeBoard 设备与 ComfyUI 执行设备是两个概念。例如 Mac 上的 TakeBoard 可以使用被转发到本机端口的远程 GPU；这不会把 Mac 项目变成服务器项目。要在服务器上管理项目，应连接服务器的 TakeBoard。

| 当前使用方式 | 项目、上传素材、已接收的生成结果 | 下载副本 |
| --- | --- | --- |
| 此电脑 | 此电脑选择的文件夹 | 此电脑的下载位置 |
| 远程 TakeBoard | 远程设备选择的文件夹 | 当前操作电脑的下载位置 |

## 安装的是应用，不是源码

客户端与服务器使用同一套原生安装包，不需要 Node.js、pnpm 或自行编译。

- macOS：安装 DMG 中的 App，放在 `/Applications/TakeBoard.app`。
- Windows：运行 EXE 安装器，使用默认的当前用户或系统安装位置。
- Debian/Ubuntu：安装对应架构的 `.deb`。没有桌面的服务器也可以安装同一个包；SSH 启动时只运行其中的 Node 服务，不运行图形窗口。包管理器可能同时安装桌面依赖。

Linux 安装命令示例（替换为实际下载文件名）：

```bash
sudo apt install ./TakeBoard_<版本>_amd64.deb
```

首次安装在目标设备进行，需要设备所有者授权。连接客户端不会擅自安装或升级远端应用，也不会安装 ComfyUI、模型或驱动。非 Debian 系 Linux、非标准安装目录和旧版服务仍可先通过原有方式启动，再填写实际 TakeBoard 端口连接；不宣称支持所有 Linux 安装体系的一键部署。

## 远程连接与启动

SSH 主机可以填 `user@192.168.1.10`、可达的域名或系统 SSH 别名。自定义 SSH 端口、密钥和跳板机沿用系统 SSH 配置。“服务端口”指 TakeBoard 端口，不是 SSH 端口。Tailscale 只是可选网络通道。

- 已运行：核对服务身份，复用现有服务和实际端口。
- 已安装但未运行：显示版本和数据位置，用户选择“允许启动并连接”后才启动。
- 进程尚未就绪、身份变化或启动失败：明确报错，不强制终止未知进程、不尝试另一个数据实例。
- 旧版或限制为仅转发的 SSH 账号：仍支持验证 `48120–48139`；范围外可手动填写实际端口。

自动启动使用 SSH 账号的默认 `~/TakeBoardData`（或该 SSH 环境明确配置的 `TAKEBOARD_DATA_ROOT`），不会猜测多个自定义目录。启动日志位于该位置的 `.system/remote-start.log`。远端不同账号、不同数据目录视为不同实例。

桌面 SSH 连接依赖已经配置好的密钥和可信主机指纹，不保存密码，也不会关闭指纹校验。尚未配置 SSH 的用户仍需完成首次系统配置。设备名称仅用于显示，不授予访问权限；Portal 仍需自托管、登录和显式设备配对，不是默认提供的公共云。

关闭远程窗口会释放本次 SSH 转发，不取消服务端生成任务，也不停止远端 TakeBoard。回到“使用此电脑”不移动或合并两台设备的数据。

## 项目文件夹

本机桌面应用使用系统文件夹选择器；远程页面浏览的是服务器文件夹，不是客户端文件夹。浏览器版也提供设备端文件夹浏览与完整路径输入。

文件夹选择会在指定父目录下创建独立的 `项目名称 (唯一标识).takeboard` 文件夹，不覆盖已有项目。下次新建使用“设置 → 项目与存储”中明确保存的设备默认位置，单次选择不会修改默认值。改项目名称不会自动移动磁盘文件夹。

设备本机访问者与管理员可以选择其他位置；普通账号成员不能借此浏览整个服务器磁盘，仍使用默认项目位置。允许的位置必须已存在且可读写，拒绝磁盘根目录、内部目录、项目内部目录、路径穿越和越界符号链接。

实例数据目录保留一个小型位置索引，因此需要同时保留实例目录和外部项目文件夹。磁盘离线时项目会标记位置不可用，不能偷偷创建空项目替代。重新连接原磁盘后可继续打开。

删除外部位置项目时，先按既有规则处理生成任务，再把索引移入回收站；原文件暂留在原盘，不跨磁盘搬动大视频。恢复会重新启用该索引。删除不是立即释放磁盘空间；不要在生成或打开项目时手动删文件。

完整项目包、实例备份读取真实项目内容，不只备份索引。备份时外部位置不可读会报错，不产出假完整备份；恢复到其他实例时项目成为默认目录下的自包含副本，不自动写回原服务器路径或覆盖原盘文件。

## ComfyUI 与更新边界

TakeBoard 连接成功不代表 ComfyUI 已运行。生成环境有独立状态；启动仍受内存、显存、负载和启动器预检约束。

安全停止只对本次服务进程可验证所有权的启动器开放（受管进程、可核对 InvocationID 的 systemd 服务）。项目有未结束任务、实际 ComfyUI 队列非空、检查失败或所有权变化时拒绝停止。外部启动的服务、尚不能验证所有权的 LaunchAgent / Windows Service 不显示为可安全停止，应使用其原管理方式。

当前开发版支持后台检查、稳定/测试版频道、跳过版本与匹配安装包下载提醒；不会自动安装或重启。见[设置与更新](settings-and-updates.md)。后续应用内安装需要签名更新包、更新前备份与迁移检查。客户端与服务器独立更新，客户端连接不能顺便替服务器升级。
