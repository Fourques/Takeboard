# v0.2.0-beta.13 · Mac 创作体验测试版

本版提供 Apple Silicon（M 系列）Mac 的 DMG，用于检查本轮资产与详情交互。

- 资产库识别画布中的生成结果；双击定位已有内容或所属镜头的历史结果，不再误建重复节点。
- 同名素材增加显示编号，结果记录中的输入素材和可解析的 @ 引用可跳转查看；保留原文件与生成历史。
- 默认导航移除镜头总览，排序、粗剪和批量审片由启用后的扩展进入。
- 工作流库入口融入模型标题行；参考图精度和视频原声使用统一的普通参数控件。
- 移除画布上的重复场景编号和标题；登录弹窗在常用桌面窗口下完整显示。

本地完整代码验证、66 项非 GPU 浏览器回归，以及收尾的 4 项创作/账号/无障碍补验均通过。视频定位使用可播放的 WebM 文件与明确标记的结果测试数据，不冒充真实 GPU 生成验证。Mac 安装包还需通过最终 DMG 内置服务运行检查；人工交互由实机验收。

安装前保存并备份项目，等待生成结束，退出旧应用后将新版拖入“应用程序”替换。项目数据不随应用替换而删除。连接远程 TakeBoard 项目时，远端服务需另行升级。

这是临时签名测试包，尚无 Apple 公证。ComfyUI、模型和第三方节点不包含在安装包中。
