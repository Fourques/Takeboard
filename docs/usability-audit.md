# TakeBoard 易用性与可靠性审计

更新时间：2026-08-30

## 本轮覆盖的完整旅程

本轮按“取得项目 → 首次安装 → 本机启动 → SSH 远程访问 → 创建项目 → 连接 ComfyUI → 导入/绑定 Workflow → 生成与查看真实进度 → 网络重连 → 停止任务 → 删除与恢复项目 → 诊断和维护”检查，而不是只检查单个页面。

已经补齐的关键断点：

- Mac、Windows 双击入口和跨平台中文启动器；
- 依赖、源码与生产构建的新鲜度检测，更新后自动重建；
- 数据目录写入预检、重复启动锁、带实例身份的安全停止和日志轮换；
- SSH 本地端口避让，以及远端 `48120–48139` 实际服务端口自动发现；
- ComfyUI WebSocket 真实节点进度，未提供步进时不伪造百分比；
- 跨项目任务中心、可选系统完成通知，以及从任务直接返回所属项目；
- 可复制/下载的脱敏运行诊断，覆盖数据写入、磁盘、网页构建、ComfyUI、监听边界和备份新鲜度；
- 按项目和原件/代理/渲染/Recipe/备份分类的存储统计；
- 生成前对项目盘与 ComfyUI 输出盘执行带安全余量的容量预检；
- 长视频无限时同步与临时网络错误自动重连；
- 删除项目之前按 Prompt 精确停止运行/排队任务，无法确认时保留项目；
- 可视化项目回收区与一键恢复；
- 自定义 Workflow 的显式 Binding、内容哈希、信任和执行前校验；
- 普通 Workflow JSON 导入后立即进入真实诊断与映射向导，不再提前绑定到镜头；
- 自动识别 `num_frames` / `frame_count` 等视频长度输入，并以受限规则按 FPS 换算；
- 流式项目包导出、隔离导入、逐文件 SHA-256 校验和同项目身份冲突保护；
- 数据库升级前一致性备份，以及迁移失败后的自动回滚；
- 回环监听、Host/Origin 边界、安全响应头与生产构建浏览器验收；
- 移除仓库中的个人机器绝对路径，使部署脚本可由 `HOME`、`COMFY_DIR` 和 `TAKEBOARD_REPO_DIR` 配置。
- React 页面异常恢复入口和服务/SSH 断开时的可执行错误说明；
- 浏览器级字体比例，保持画布坐标和生成分辨率不变；
- 数字输入草稿与已提交值分离，空值不会自动注入旧值或前导零；
- 将按镜头顺序播放已采用结果的只读粗剪移入默认关闭的扩展；核心分镜墙仍保留顺序、覆盖率和计划空镜。
- 默认关闭、显式指向外部卷的定时实例备份，包含原子复制、SHA-256、日/周/月保留、损坏提示和真实隔离恢复演练；
- 内置 Node.js 的六种 OS/CPU 便携构建、归档后自检、校验和与 GitHub 构建来源证明；
- 可复现的产品演示录制，以及不把模拟候选冒充模型质量的清单；
- GPU Gate v2 与机器可读兼容矩阵，未提交真实证据的组合不会显示为已验证。

## 仍应继续建设的产品能力

以下不是本轮可以安全“顺手补上”的小改动，应该作为独立里程碑设计和验收：

1. **增量与去重备份**：跨存储完整快照、保留策略和恢复演练已经具备；大媒体项目仍需要内容寻址增量复制、加密建议和长期演练记录。
2. **签名桌面安装包**：未签名 Tauri 安装预览、内置 Node.js、启动自检和六平台 CI 已具备；Apple notarization、Windows 商业签名、自动更新和三种净机人工验收仍需要发布凭据与真实设备。
3. **远程身份认证**：已提供账号、设备会话、项目角色和安全审计；面向非可信公众运营前仍需 MFA、邮件恢复、组织/配额和安全运营能力。
4. **Workflow 发布桥接**：Recipe 包、UI Workflow 转换、依赖清单、参数候选和结构化兼容性反馈已经具备；仍需在 ComfyUI 侧提供一键发布扩展，并补充 Custom Node 包名与版本锁定。
5. **存储生命周期策略**：容量统计和生成前预检已经具备；仍需回收区保留策略、跨项目内容去重和受保护的永久清理流程。
6. **真实用户任务测试**：自动化黄金路径不能替代陌生创作者；需要 5 名用户各自带 Workflow 完成安装、映射、生成、选片和迁移，并记录支持时间。

## 后续验收门槛

- 任意失败都必须告诉用户“发生了什么、数据是否安全、下一步是什么”；
- UI 不得把估算值描述成真实进度，也不得把“请求已发送”描述成“任务已停止”；
- 删除、停止、恢复和升级必须具备幂等性，重复操作不能扩大影响范围；
- 默认只监听回环地址，远程入口继续使用标准 SSH 或带认证的反向代理；
- 跨平台功能至少通过 macOS、Windows、Linux 的路径与端口差异检查后再标记为可用。
