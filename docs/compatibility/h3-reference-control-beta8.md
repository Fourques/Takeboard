## 固定项

- 同一参考图片、参考视频；提交前核对文件 SHA-256。
- 同一已成功执行的 API Prompt 节点图、模型与连接。
- Seed `26081307`，1344 × 768，24 FPS，124 帧，20 steps，`res_multistep` / `beta`，denoise 1，参考图片尺寸 `match`。
- 保持原任务已启用的参考视频音轨，以免引入第二个参数变量。
- 只修改提示词与独立的验收输出前缀；提交脚本通过深度比较确认其他字段未变。未改动用户项目或替换已采用结果。

## 唯一实验变量

将简短的“图片人物抱着视频中的猫”改为明确的参考角色、保留内容、镜头构图和连续动作描述。按 [MiniMax 官方全参考提示词指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)区分人物与猫这两个主体，明确视频提供猫的外观而非必须复制的特写构图。

## 观察结果

- 历史基线偏向猫的特写，人物脸部未完整呈现；本次每秒抽帧检查显示人物完整头部、白绿色服装和抱猫动作，猫与人物同框。
- 输出为 H.264 / AAC、1344 × 768、24 FPS、124 帧，约 5.167 秒；ComfyUI 执行完成约 24 分 47 秒。
- 这说明本次素材与模型组合能完成所需构图，不能推导出所有素材的人物相似度都已解决。人物相似度与观感仍需用户确认。
- 因采用整组结构化描述，本实验不能区分改善究竟来自英文、主体分离还是更明确的构图要求；需要更多单变量实验才能细分归因。

原始素材、私有提示词、输出视频与逐帧截图不上传仓库。TakeBoard 不自动改写用户提示词，不把这个单样本结果当作通用推荐参数，也不因此默认开启参考视频音轨。
