## 事实与边界

- 2026-09-11：Mac beta.7 曾在新生成时发生 React #185；服务器 SH-03 已收到任务，不能重复提交作为页面恢复方法。
- Mac Downloads 中实际存在此前保存的异常报告，旧按钮缺少反馈；已增加桌面保存对话框、结果反馈、复制和文本兜底。浏览器实际下载通过；桌面 Rust 编译与 3 项原生单元测试通过，Mac 新包交互仍待验证。
- 批次进度返回新对象，而画布 effect 依赖该对象并更新节点；已稳定进度对象引用。Mac 现场确为 4 结果批次，恢复批次回归通过，不通过重复提交任务恢复页面。
- H3 先前参考任务确实接入图片和视频，输出近似参考视频。提示词、模型适配等原因尚需对照，不承诺改提示词即解决。
- 保留已有工作区改动、原始素材、运行历史和已存在的候选节点；不以清理名义删除用户内容。

实施状态和验证结果随工作更新；未勾选项目不得宣称完成。

## 参数与安全复核

2026-09-11 本地验收：最终源码 `pnpm verify` 通过（329 项业务测试、50 项脚本测试），完整 Playwright 54 项通过（含 500 节点性能测试），Rust `local_files::tests` 3 项通过。时长换算必须绑定 FPS，防止表单与实际视频帧率不一致；同一素材重复用于不同输入位置的提交与历史记录已通过服务端回归。浏览器由独立 Playwright 执行；会话内浏览器工具无可用实例。Mac 安装包原生对话框与 H3 GPU 画质不计入这些结果。

- 重命名不能改变模型约束；原生适配依据路径，自定义图依据绑定，不根据用户显示名称推断模型。
- 已绑定图读取无歧义的数值默认值；帧数按已声明的转换反算时长。连线计算值、不同绑定位置的不同值不冒充统一默认值，应在配置时核对。
- 自定义偏好与编辑草稿按工作流内容哈希隔离；可选本地存储失败不导致页面崩溃。
- PNG 验证块边界、CRC、元数据重复及解压上限；普通截图不是工作流，不执行导入文件中的代码。
- 列表偏好修改在当前实例内串行合并；不复制执行信任、不重命名真实文件、不移动生成历史。
- 缩放失败只恢复当前项目对应节点，不覆盖其他项目或其他节点的更新。
- Mac 实机验收发现 `/tmp` 到 `/private/tmp` 的路径别名使脚本错误跳过入口；更新、连接与远端管理已统一按真实路径识别入口。安装包运行时验收也强制经目录别名启动，避免只在标准安装目录通过。
