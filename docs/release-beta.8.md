# v0.2.0-beta.8 · 创作流程统一升级

发布目标：Mac Apple Silicon（M 系列）调试版。此文件记录源码变更，不表示安装包已发布。

## 变化

- 修复批量生成或恢复任务时的 React 更新循环。
- 异常报告增加原生保存对话框、保存反馈、复制与文本兜底。
- 修复路径别名下更新、远程连接和远端服务脚本没有返回结果的问题。
- 工作流按已添加、可选模板和全部发现组织，支持收藏、重命名和从列表移除。
- 导入 JSON 或带工作流元数据的 PNG 后直接检查；可编辑副本不继承执行信任。
- 自定义工作流恢复明确的真实参数默认值；显示名称不会改变模型约束。
- 素材输入、引用和数量不再静默丢弃；参考视频原声改为显式选择。
- 新镜头放入当前视野，节点可缩放，生成记录支持取消采用和多个结果独立入画布。
- 资产库与工作画板采用侧边面板，首页缩略画布展示真实媒体与连线。

## 验证边界

本地完整验证通过：329 项业务测试、50 项脚本测试、54 项浏览器测试及 3 项原生测试。

H3“图片人物与视频中猫互动”的真实画质对照尚未完成，不能宣称此次修改保证解决模型遵循问题。
原生模板仍使用版本控制的适配器；需要改节点时创建自定义副本并完成绑定。
PNG 需带工作流元数据，普通截图不可导入为工作流。模型与自定义节点仍需在生成设备安装。

安装包不含模型、没有 Apple 公证；不自动替换正在使用的应用，不迁移或删除已有项目。
