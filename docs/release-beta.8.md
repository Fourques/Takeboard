# v0.2.0-beta.8 · 创作流程统一升级

已发布：[Mac Apple Silicon（M 系列）调试版](https://github.com/Fourques/Takeboard/releases/tag/v0.2.0-beta.8)。仅提供一个 DMG 安装包。

## 变化

- 修复批量生成或恢复任务时的 React 更新循环。
- 异常报告增加原生保存对话框、保存反馈、复制与文本兜底。
- 修复路径别名下更新、远程连接和远端服务脚本没有返回结果的问题。
- 远程项目连接整合进设置；删除独立配置窗口，旧连接记录迁移保留，实际远程项目仍在独立工作窗口中打开。
- 工作流按已添加、可选模板和全部发现组织，支持收藏、重命名和从列表移除。
- 导入 JSON 或带工作流元数据的 PNG 后直接检查；可编辑副本不继承执行信任。
- 自定义工作流恢复明确的真实参数默认值；显示名称不会改变模型约束。
- 素材输入、引用和数量不再静默丢弃；参考视频原声改为显式选择。
- 新镜头放入当前视野，节点可缩放，生成记录支持取消采用和多个结果独立入画布。
- 资产库与工作画板采用侧边面板，首页缩略画布展示真实媒体与连线。

## 验证边界

本地验证通过：329 项业务测试、50 项脚本测试、54 项完整浏览器回归及新增启动入口专项（合计 55 项浏览器用例）、5 项原生单元测试。

最终候选包基于 `6100ac0`，[Mac 构建](https://github.com/Fourques/Takeboard/actions/runs/34584345649)与同提交 CI 均通过。用户 Mac 实测通过：DMG 完整性、临时签名完整性、隔离包内运行环境，以及设置内连接真实临时服务、取消断开、确认断开、移除记录。快捷键只打开主窗口设置，实际远程项目另开工作窗口。测试服务与记录已清理，未覆盖原 App 或修改用户项目。

原生报告保存、取消与反馈已在首轮 `c83a14b` 候选包上实际通过；后续未修改该功能。最终 DMG SHA-256：`da2227548c844c5cd25492019e83f325baf345d73f4475291d4e92a6a83dfba8`。上述测试不等于 Apple 公证，也不冒充新一轮真实 SSH / Portal 端到端验收。

H3“图片人物与视频中猫互动”的一次真实对照已完成，结果中人物头部完整、人物与猫同框互动；见[对照边界](compatibility/h3-reference-control-beta8.md)。不能宣称单次实验保证解决所有素材的人物相似度。
原生模板仍使用版本控制的适配器；需要改节点时创建自定义副本并完成绑定。
PNG 需带工作流元数据，普通截图不可导入为工作流。模型与自定义节点仍需在生成设备安装。

安装包不含模型、没有 Apple 公证；不自动替换正在使用的应用，不迁移或删除已有项目。
