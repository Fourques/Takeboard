# 详情与画布交互整理

本轮针对 beta.11 后发现的使用问题，不改变项目存储格式、生成执行协议或安装器。

## 产品决策

- **不再自由拉伸节点。** 镜头节点承载生成控件，不是任意尺寸的图片框。手动高度会破坏控件布局，因此移除控制点与拉伸样式；用画布缩放查看细节。媒体保留原比例，节点高度由内容决定。旧项目的手动尺寸不再用于显示，但原数据、坐标、历史记录和兼容接口保留。
- **查看模式与选中对象分开。** 已打开详情时，单击其他镜头或素材切换详情对象；快速查看时则保持画布内操作。双击进入详情，点击空白画布退出。多选、右键、专注模式仍按原有独立规则处理。
- **同类详情共用媒体呈现。** 资产库、画布素材、角色参考和生成结果统一使用 `DetailMedia`，读取原文件、自然比例、透明容器，不用定高白底补齐比例。视频使用真实解码帧与原生播放控件，文件失败时明确显示不可预览。
- **结果信息分层。** 记录按工作流/模型、提示词、输入素材、关键参数展示，完整参数与执行信息收在同一个次级入口。图片不显示无意义的时长/帧率。旧数据没有模型名称时不冒充可读信息，也不显示内部编号作为标题。
- **提示词提示只有一个来源。** 画布和右侧参数面板共用按任务区分的占位提示；删除重复的提示词结构说明。参考素材保留容量、已连接数量和可引用的素材名，弱化卡片边框；参考图精度仍是可选参数，不默认占据主体。
- **镜头总览与资产库保留不同职责。** 总览处理镜头顺序、已采用结果、粗剪及可选跨镜头审批；资产库处理文件分类、标签、检索和复用。保留有价值的镜头编排，不另建重复的文件管理入口。
- **账号入口回归账号本身。** 默认个人资料，通用标题与占位，保留用户实际填写的名字。导航与内容独立滚动，小窗口不截断内容；外部点击、Escape 与焦点返回保持一致。镜头总览也共用外部关闭层，并明确内容层级，避免关闭层挡住播放按钮。

## 可复验流程

```sh
pnpm verify
pnpm exec playwright test --grep-invert @gpu
```

新增回归覆盖旧尺寸恢复、连续查看、横竖图自然比例、视频解码/播放/边框、生成记录与完整参数、账号窗口与外部关闭。原有创作生命周期、权限、复制撤销、素材连线、工作流管理、粗剪和 500 节点性能测试继续保留。

真实 GPU 验收独立、默认不运行：

```sh
TAKEBOARD_LIVE_REFERENCE=1 pnpm exec playwright test e2e/live-reference.spec.ts
```

该测试要求本机 ComfyUI 已具备 Qwen Image 2512 I2I 依赖且队列空闲，使用仓库自带参考图、8 步、单个结果，通过页面提交，不拦截生成响应。验证真实运行输入、结果落库与读取、种子、右侧素材及参数展示；结束后删除隔离测试项目，恢复工作流列表的添加状态。ComfyUI 本身的原始输出不被测试删除。

这是一项功能链路验收，不是画质、角色一致性、任意自定义工作流兼容性或 Mac 安装包实机验收，也不替代绑定干净提交的 GPU Release Gate。

## 本轮验证结果

- 最终源码 `pnpm verify` 通过；`git diff --check` 无问题。
- 非 GPU 浏览器回归 65 项全部通过，无重试；覆盖真实媒体解码及播放、完整创作生命周期和权限边界。最后补充旧记录标题兜底后，相关 4 项浏览器流程再次全部通过。
- 500 节点场景加载 433 ms，动画帧间隔 P95 为 16.9 ms（本次 Linux/Chromium 环境，不作为跨设备性能承诺）。
- 独立真实 Qwen I2I 参考图生成完成，输入关联、结果文件读取、种子与右侧记录验证通过。第一次脚本因按钮名称不匹配而中断，未提交 GPU 任务；纠正后重新执行成功，不将中断尝试计为通过。
- 本轮没有构建或发布 Mac 安装包，也未宣称完成 Mac WebKit 实机验收。
