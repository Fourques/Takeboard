# v0.2.0-beta.9 · 模板库与镜头详情

本版仅提供 Mac Apple Silicon（M1 / M2 / M3 / M4 等 M 系列）DMG 调试安装包。Intel Mac、Windows 和 Linux 不发布本次安装包。

## 更新内容

- 精简镜头详情与模型选择，优化结果预览、批次状态和可操作的错误提示。
- 模板库统一可用性判断，阻止不可用工作流直接用于生成；保留检查、编辑和重新启用入口。
- 修复动态输入误报、具名控件值错位；只在执行副本中补齐安全默认值，不覆盖原模板。
- 新增 9 份 H3、Qwen Image、Wan 推荐配置，检查后可直接添加至当前生成设备，支持失败恢复，不覆盖已有文件。
- 完善窄窗口布局与键盘操作。

## 安装与验证边界

退出旧版 TakeBoard，将 DMG 中的 TakeBoard 拖入「应用程序」并替换旧应用；不要删除项目或应用数据目录。

这是调试版，未经过 Apple Developer ID 签名与 notarization。模板文件可自动配置，但不会自动下载模型权重或安装第三方节点。

源码已通过类型检查、构建、单元测试及浏览器回归。9 份推荐配置在当前 ComfyUI 上通过只读节点与模型选项检查，不代表本轮完成 GPU 生成质量验证或 Mac 人工交互验收。

构建流程还会挂载最终 DMG，使用包内 Node 运行时检查服务、静态页面及原生依赖。仅该检查成功后上传安装包。
