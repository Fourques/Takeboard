# v0.2.0-beta.11 · Mac M 系列调试版

本版集中改进工作区交互，仅提供 Apple Silicon（M 系列）DMG。

- 工作流卡片统一管理操作，支持点击外部关闭；打开 ComfyUI 改用桌面浏览器调用，并提供失败反馈。
- 生成类型与模型分开选择，模型随类型筛选；减少高级说明，调整参数控件布局。
- 资产库使用左侧抽屉，优化不同尺寸的素材预览和详情，增加右键下载。
- 画布支持多节点选择、复制、粘贴和批量操作的撤销／重做；输入文字及确认操作时隔离画布快捷键。
- 统一工作区顶栏、弹层与通知样式，通知不再遮挡生成操作。

安装前保存编辑、备份重要项目并等待生成结束。退出 TakeBoard，将新版拖入「应用程序」替换旧应用；不要删除项目目录或应用数据。连接远程 TakeBoard 时，远端服务仍需单独升级，安装本机新版不会自动更新远端网页。

本版仍为临时签名调试包，没有 Apple 公证。ComfyUI、模型和第三方节点不随包安装。发布前要求最终 DMG 的包内运行验证通过；Mac 人工操作和真实 GPU 生成效果留待实机验收，不将自动检查视作通过这两项验收。

本地完整发布检查与 62 项浏览器测试（含 500 节点性能检查）全部通过，浏览器测试未重试。500 节点在本次测试环境中加载 408ms，帧间隔 P95 为 16.9ms，不代表所有设备的表现。测试使用隔离数据和模拟生成服务，没有修改真实项目或提交 GPU 生成任务。

安装包来源提交 `73f9108ac42b5336a956f924d4747f9827a24045`；[Mac 原生构建、最终 DMG 包内运行验证与构建来源证明](https://github.com/Fourques/Takeboard/actions/runs/34823938816)全部通过。下载后的 SHA-256 与构建产物一致。

发布检查另发现一个 Windows 测试时序问题：第一次读取生成状态时，图片可能仍在异步回收。测试现等待真实落盘完成，保留全部素材和结果断言，修正提交为 `7087191`，没有改变安装包内的程序。[云端复验](https://github.com/Fourques/Takeboard/actions/runs/34824996085)的 Linux、Mac、Windows 发布检查、浏览器全流程及独立 500 节点性能检查均已通过。

其他平台的已知验收缺口：Linux 原生窗口检查仍在等待已迁入设置的旧远程项目窗口。本版不发布 Linux 安装包，也不将该项标为通过。
