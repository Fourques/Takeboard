# v0.2.0-beta.11 · Mac M 系列调试版

本版集中改进工作区交互，仅提供 Apple Silicon（M 系列）DMG。

- 工作流卡片统一管理操作，支持点击外部关闭；打开 ComfyUI 改用桌面浏览器调用，并提供失败反馈。
- 生成类型与模型分开选择，模型随类型筛选；减少高级说明，调整参数控件布局。
- 资产库使用左侧抽屉，优化不同尺寸的素材预览和详情，增加右键下载。
- 画布支持多节点选择、复制、粘贴和批量操作的撤销／重做；输入文字及确认操作时隔离画布快捷键。
- 统一工作区顶栏、弹层与通知样式，通知不再遮挡生成操作。

安装前保存编辑、备份重要项目并等待生成结束。退出 TakeBoard，将新版拖入「应用程序」替换旧应用；不要删除项目目录或应用数据。连接远程 TakeBoard 时，远端服务仍需单独升级，安装本机新版不会自动更新远端网页。

本版仍为临时签名调试包，没有 Apple 公证。ComfyUI、模型和第三方节点不随包安装。发布前要求最终 DMG 的包内运行验证通过；Mac 人工操作和真实 GPU 生成效果留待实机验收，不将自动检查视作通过这两项验收。

发布准备前的完整单元／集成／脚本测试及 61 项浏览器功能回归通过，浏览器回归未重试。测试使用隔离数据和模拟生成服务，没有修改真实项目或提交 GPU 生成任务。
