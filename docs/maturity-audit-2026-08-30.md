# TakeBoard 成熟度评估与发布边界

评估日期：2026-08-30

评估对象：`main` 分支的 0.2.0-beta.1 Public Preview

目标用户：个人 AI 影像创作者、同一信任边界内的自托管小团队

## 结论

TakeBoard 已达到**公开预览**门槛：陌生用户可以通过跨平台入口启动，完成项目、素材、画布、可信 Workflow、生成、候选选择、分镜和项目迁移的主流程；故障路径具备真实进度、取消、恢复、诊断和明确的数据安全说明。

它尚未达到“无需技术支持的大规模正式版”或“直接公网多租户 SaaS”门槛。当前已补上内置运行时的未签名便携包、证据驱动的 GPU 兼容矩阵框架、定时跨存储备份和自动恢复演练；仍缺 Apple/Windows 签名与自动更新、足够多的真实硬件证据、MFA/SSO、组织配额和长期运营记录。

## 评估方法

- 从首次安装、本机/SSH 启动、账号、项目、素材、Workflow、生成、恢复、删除、导入导出到诊断逐段检查；
- 对 Linux、macOS、Windows CI 安装路径和生产 Chromium 旅程执行门禁；
- 检查权限、CSRF、Host/Origin、归档解包、Workflow 信任、进程所有权和磁盘余量边界；
- 检查无 GPU、ComfyUI 离线、未知进度、网络中断、数据冲突与页面崩溃时的用户反馈；
- 将“存在代码”与“用户可完成且有证据”分开，不把未运行的真实 GPU 路径标为本轮通过。

## 本轮关闭的高影响问题

1. **Windows 安装阻断**：回退到为 Node 24 提供 Windows 预构建二进制的 `better-sqlite3` 版本，避免把 Visual Studio C++ 工具链作为隐式前置条件。
2. **远程故障不可解释**：网络与超时错误现在明确提示服务/SSH 检查；运行中心可下载不含项目名、账号、提示词、路径和密钥的诊断报告。
3. **页面崩溃白屏**：React 根边界提供异常编号、重新加载、返回主页和显式下载报告，并诚实说明未提交文字可能丢失。
4. **不同屏幕文字过小**：字体比例成为浏览器级用户设置，并覆盖账号、项目、画布、检查器、分镜和运行中心；不缩放 React Flow 坐标，也不改变生成分辨率。
5. **数字输入回填旧值**：编辑草稿与已提交数值分离；空值保持可编辑但阻止生成，Esc 才恢复，合法提交后再限幅/步进。
6. **整片节奏不可见**：核心分镜墙提供顺序和覆盖率；需要节奏检查时启用只读粗剪扩展，开放镜头用计划空镜占位，不错误展示未批准候选。
7. **支持入口不完整**：补齐结构化 Bug、Workflow 兼容性、功能建议和 PR 模板，以及英文项目入口。
8. **备份仍靠人工下载**：增加默认关闭、显式配置的跨存储计划，原子复制、SHA-256、日/周/月保留、损坏检测和真实恢复演练进入管理员 UI 与脱敏诊断。
9. **跨平台下载没有可执行证据**：增加六种 OS/CPU 原生便携构建、归档后解压自检、内置运行时、SHA-256 与 GitHub 构建来源证明；仍不冒充已代码签名。
10. **兼容性容易变成口头承诺**：GPU Gate 升级为隐私受限的 v2 证据，矩阵只收录真实通过的具体 Workflow 哈希和硬件组合；旧 4090 结果降级为历史基线。

## 不应被宣传成已完成的能力

- 任意 ComfyUI Workflow “放入 JSON 即可运行”；真实边界是“可导入诊断，完成可信 Binding 后运行”。
- 对所有 GPU、模型和 Custom Node 组合的兼容保证；兼容性取决于受验证矩阵。
- 已有内置 Node.js 的便携预览包，但不是签名安装器、自动更新客户端或消费级桌面应用。
- 公网多租户 SaaS、企业身份、计费、配额或托管安全运营。
- 自动成片、完整 NLE 或对原媒体进行非破坏剪辑；可选粗剪扩展只做只读节奏检查。

## 下一阶段优先级

### P0：公开预览后的真实用户 Gate

- 选择 5 名使用不同电脑与 Workflow 的创作者，不远程代操作，记录完成率、阻断点和支持时间；
- 每周至少跑一次私有真实 GPU Gate，并记录模型、Workflow 哈希、ComfyUI/节点版本和输出结果；
- 在 macOS、Windows、Linux 净机上由陌生用户验证便携包、升级和数据保留。

### P1：正式版基础设施

- 签名/notarized 桌面安装包、可回滚自动更新（未签名便携包已完成）；
- 增量/去重外部备份、加密建议和季度恢复记录（完整快照自动化已完成）；
- 回收区受保护永久清理与按年龄/容量建议，不做静默自动删除；
- 扩充 Workflow/Binding 真机证据矩阵，并完成 ComfyUI 侧发布桥接。

### P2：团队与规模

- MFA、恢复邮箱、SSO/SCIM、组织、配额和安全告警；
- 多 Worker 核心调度与可选的跨镜头审批扩展已完成首版；下一步用真实多节点、并发、断线和不同币种场景建立运行 Gate；
- OTIO/代理预览导出，以及具备真实账单接口的 BYOK Provider Adapter。

## 发布判定

- **允许**：GitHub Public Preview；个人本机；SSH 远程；可信团队经 HTTPS 反向代理自托管。
- **有条件允许**：使用自定义 Workflow，前提是 Binding、内容哈希、依赖与信任检查全部通过。
- **不允许宣称**：生产稳定版、通用 Workflow 执行器、零配置桌面应用、公网多租户 SaaS。
