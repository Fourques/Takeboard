# TakeBoard v0.2.0-beta.14

创作体验与生成资源管理测试版。

- 优化画布连线标签、生成参数、比例预设、资产命名和结果详情。
- 连接设置新增“释放显存”，检查空闲状态后卸载模型，保持服务连接。
- 完成/失败后安排空闲清理；退出时清理自有空闲服务，重开时恢复已授权服务。
- 桌面退出后短暂收集已提交任务的结果；异常或超过 30 分钟收尾上限结束等待，不无限保活、不自动重新生成。
- 修复进度 WebSocket 连接失败可能造成后台栈溢出的问题。
- 增加显式配置的 NVIDIA 单卡独立实例执行池，包含预算、定向取消及独立输出归档。

## 验证与限制

完整 `pnpm verify` 已在版本更新前通过，发布时再次验证版本更新后的代码。
RTX 4090 实测通过双实例 H3 VAE 编解码、定向取消与资源释放；
**尚未验证两路完整 H3 视频生成，24 GB 显存不代表能同时运行两份完整 H3 工作负载。**
真实 Node 子进程 IPC 断开测试验证了保存结果、释放请求和后台退出（使用模拟 ComfyUI）。
这不等于 Mac/Windows 原生强制退出已全面实机验收，也不能保证断电或强杀所有后台进程仍能收尾。

安装包：Mac M 系列 `.dmg`；Windows x64 / ARM64 `.exe`，按设备架构选择。
本版沿用预览构建方式，未进行 Apple notarization 或 Windows 商业证书签名。
没有向原服务自动部署；安装更新后才使用本版逻辑。
