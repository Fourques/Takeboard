# TakeBoard v0.2.0-beta.16

Mac M 系列设备身份与重连修复版。

- ComfyUI 离线时也能保存设备，不再要求先有可用端口。
- 重连、服务重启和编辑 SSH 服务端口保持原设备 ID。
- 默认端口候选不再混入已选择远程设备的执行池；已明确配置的本机服务仍保留。
- TakeBoard 自有隧道端口归回原设备，新增和修改接口阻止重复登记。
- 展示连接中、启动中、服务未就绪、断开和恢复状态。
- 修复首次无项目目录时保存设备失败、回环地址连接类型校验不一致的问题。

## 验证与边界

源码完整验证、真实本地 HTTP 服务启停测试及 8 项浏览器回归已通过。SSH 恢复使用可控测试传输，本轮尚未完成用户 Mac 与远程 ComfyUI 的实机验收。
外部手动转发、不同 SSH 别名之间尚不能可靠自动合并，不会猜测设备归属或删除历史绑定。详见 [设备身份说明](../device-identity.md)。

本版仅发布 Apple Silicon（M 系列）DMG，流水线验证最终安装包内运行时。未进行 Apple notarization。退出旧版后替换应用即可，项目数据不随应用替换删除。
