# TakeBoard v0.2.0-beta.18

安全与稳定性更新。建议使用旧版的用户升级；自托管 Portal 也应更新依赖并重启服务。

## 本版更新

- 修复生产依赖的 2 项高危、4 项中危审计记录：`brace-expansion` 升至 5.0.12，`fast-uri` 的两条依赖链分别升至 3.1.8、4.1.5。没有忽略告警或跨主版本强制替换。
- 改善 ComfyUI 健康检查的失效连接恢复，避免任务取消等待不必要的资源清理；生成提交不会自动重放。
- 修复示例项目的模拟结果显示，更新 SQLite 运行时打包和 Linux 原生验收脚本。

## 下载与升级

按电脑系统和芯片选择一个安装包：Mac 使用 DMG，Windows 使用 EXE，Debian/Ubuntu 使用 DEB。Apple Silicon 对应 `aarch64.dmg`，Intel Mac 对应 `x64.dmg`。

先备份重要项目，退出旧版后安装新版。无需删除项目目录。安装包包含 TakeBoard 运行时，不包含 ComfyUI、模型或第三方节点。更新桌面端不会替远程服务器更新 Portal 或 TakeBoard。

## 验证与限制

安全依赖修复已通过全量与生产 npm 审计、全项目构建、类型检查和自动化测试。新增测试覆盖 URI 主机归一化、mailto 解析、括号展开边界及 Fastify Schema 兼容性。

安装包仅在所选六个平台全部完成构建、最终包内运行时检查与校验后发布。本轮没有新增真实 GPU 生成验收；交互演示中的模拟结果不代表模型输出。

本版仍为预览版：macOS 未做 Apple notarization，Windows 未做商业代码签名。Linux GTK 上游已知告警的受限例外仍保留，详见 [安全说明](https://github.com/Fourques/Takeboard/blob/main/SECURITY.md)。npm 审计通过不代表整个产品不存在安全风险。

## English

Security and stability update. Updates brace-expansion to 5.0.12 and fast-uri to 3.1.8 / 4.1.5, resolving the reported production dependency advisories without changing major versions. Also includes connection recovery, cancellation, simulated-demo rendering and SQLite packaging fixes since beta.17.

Back up important projects, close the old app and install the package for your OS and CPU. ComfyUI and models are not bundled. Remote TakeBoard and self-hosted Portal deployments must be upgraded separately. Preview installers are not Apple-notarized or commercially signed on Windows. The documented Linux GTK advisory exception remains; no new real-GPU validation is claimed.
