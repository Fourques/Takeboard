## 这一版更新了什么

- 本机直接使用，或连接远程 TakeBoard；顶栏清楚显示设备与项目位置。SSH 可经确认启动已经安装的远程 TakeBoard，断开连接不会取消服务器上的生成。
- 统一设置入口，支持设备默认项目文件夹；单次选择不改变默认值，也不移动已有项目。目录离线不会偷偷改存到其他位置。
- 新项目、本机文件夹选择器、远程文件夹浏览与原文件下载使用一致的设备归属。
- 新增桌面更新检查、稳定／测试频道、跳过版本与匹配此电脑的下载提醒；不自动安装、不重启远程服务。
- 默认柔彩主题，主题、字体大小与三维效果偏好可以保留；修复浏览器存储受限、设置快捷键误触画布、顶栏遮挡与头像比例问题。
- 统一 Windows 原生路径解析，保留目录越界与符号链接防护。

## 如何升级

先备份重要项目，等待本机任务结束并退出旧 TakeBoard，再运行新版安装包。Mac 打开 DMG，将 TakeBoard 拖入“应用程序”并替换旧 App。不要删除 `TakeBoardData` 或外部项目目录。

旧 `0.2.0-beta.2` 没有本次新增的更新检查入口，这次需要手动下载安装；从本版开始可在“更新 → 检查更新”查看后续版本。远程电脑应单独升级，需要服务所有者操作。

## 预览版边界

- macOS 包使用临时签名，尚无 Apple notarization；Windows 尚无商业代码签名。系统仍可能提示未知开发者，请确认官方来源，不要全局关闭系统防护。
- 不包含 ComfyUI、模型和自定义节点。安装器验收不等于所有 GPU／工作流兼容性证明。
- Linux DEB 面向 Debian/Ubuntu；现有 GLib 上游间接依赖告警与限期例外仍保持公开，不宣称已经消除。
- 更新检查只请求官方 GitHub 发布信息，不上传账号、项目或素材；可在桌面更新窗口关闭后台检查。

Source code 是开发者源码，不是安装包。校验值和构建来源证明保留在 Actions，不增加普通用户下载项。
