# TakeBoard v0.2.0-beta.19

依赖安全更新。建议 beta.18 及更早版本用户升级。

## 本版更新

- Server 与 Portal 升级到 Fastify 5.12.5，修复本次报告的 4 项高危和 1 项中危告警，覆盖请求验证、异常 URL 路由和 HTTP/2 trailer 拒绝服务问题。
- 为两端添加全部五类漏洞的行为回归测试，并接入持续安全审计；没有忽略告警或降低审计标准。
- 最终安装包检查会执行包内 Node，确认实际 Fastify 版本与已审查依赖一致，避免只更新源码而漏掉分发运行时。

## 下载与升级

Mac 使用 DMG，Windows 使用 EXE，Debian/Ubuntu 使用 DEB。每个平台提供 x64 与 ARM64；Apple 芯片选择 `aarch64.dmg`，Intel Mac 选择 `x64.dmg`。

先备份重要项目，退出旧版后安装新版，无需删除项目目录。安装包不包含 ComfyUI、模型或第三方节点。

**更新桌面端不会替远程服务器更新 TakeBoard 或 Portal。** 自托管部署需要更新源码与依赖，或重新构建容器，并通过原有服务管理方式重启。旧 beta.18 安装包不含本次 Fastify 修复。

## 验证与限制

源码已通过生产与完整依赖审计（零项已知 Node.js 漏洞）、全项目检查和自动化测试；浏览器回归 70 项通过，1 项真实 GPU 测试跳过。独立旧版本验证能够检出漏洞行为，更新后的生产依赖打包通过安全回归。

六个平台全部完成构建、最终安装包内运行时检查与完整性校验后，才会发布安装包。这不是新增原生 UI 或真实 GPU 生成兼容性声明。

仍为预览版：macOS 未完成 Apple notarization，Windows 未使用商业代码签名。Linux GTK 已知上游告警的受限例外仍保留，详见[安全说明](https://github.com/Fourques/Takeboard/blob/main/SECURITY.md)。Node.js 依赖审计通过不代表整个产品没有安全风险。

## English

Security update: server and Portal now use Fastify 5.12.5, addressing four high-severity advisories and one moderate HTTP/2 trailer denial-of-service advisory. Behavioral regressions cover all five cases for both applications. Final installer checks also execute the bundled Node runtime to verify its Fastify version.

Back up important projects, close the old app and install the package for your OS and CPU. ComfyUI and models are not bundled. Remote TakeBoard and self-hosted Portal must be updated separately; beta.18 installers do not contain this fix.

Preview installers are not Apple-notarized or commercially signed on Windows. The documented Linux GTK exception remains. No new real-GPU or native-window compatibility validation is claimed.
