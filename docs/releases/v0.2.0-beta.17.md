# TakeBoard v0.2.0-beta.17

Mac M 系列设备状态与连接设置改进版。

- 分开显示 SSH 设备连接、GPU 资源和 ComfyUI 服务状态；服务未启动不再等同于设备离线。
- 服务未运行时也通过 SSH 读取设备名称、系统、显存和 GPU 进程信息。
- 整合启动、重连与资源提示，避免同一页面重复按钮和警告。
- 保持设备身份，清理已删除设备的状态缓存，防止异步结果重新写回。

## 验证与边界

源码检查、自动化测试及设备设置浏览器回归已验证。实际通过 Mac 的 SSH 连接读取了远端设备与 GPU 状态。

真实空 ComfyUI 启动因远端仅余约 265 MiB 显存而发生 CUDA 内存不足；已停止本次服务重试，未影响其他 GPU 任务。本版不宣称完成真实生成或完整启停验收。

仅提供 Apple Silicon（M 系列）DMG，构建流水线检查最终安装包内运行时。未进行 Apple notarization。退出旧版后替换应用，项目数据不会随应用替换删除。
