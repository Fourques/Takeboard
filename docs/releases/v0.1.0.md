# TakeBoard v0.1.0 — Public Preview

TakeBoard is an open-source, local-first production board for ComfyUI filmmakers. It keeps source
assets, semantic shot inputs, trusted workflows, generation runs, candidate takes and approvals in one
project instead of scattering them across folders and browser tabs.

## Highlights

- Visual project hub and production canvas with clean source/shot provenance.
- Original image and video ingest without destructive resizing or cropping.
- Built-in Recipes and content-hash-bound mappings for trusted custom ComfyUI workflows.
- Real node progress when ComfyUI exposes it, honest indeterminate states otherwise, plus cancel and
  reconnect reconciliation.
- Candidate review, approval, storyboard coverage and an ordered read-only rough cut.
- Accounts, device sessions and project Owner/Editor/Viewer permissions for trusted teams.
- Recoverable project deletion, integrity-checked archives and pre-migration backups.
- Cross-platform easy launchers, SSH remote helper and guarded local ComfyUI startup.
- Redacted runtime support reports, display scaling and a browser crash-recovery surface.

## Intended users

This preview is for individual creators and trusted self-hosted teams that already use or plan to use
ComfyUI. It remains useful as a project/asset/shot workspace while ComfyUI is offline.

## Important boundaries

- Imported UI Workflow JSON is diagnosable but not executable by filename. A custom workflow needs an
  explicit, trusted Binding tied to its content hash.
- TakeBoard does not auto-install models or Custom Nodes.
- Services listen on loopback by default. Use SSH for personal remote access or a hardened HTTPS reverse
  proxy for a trusted team; never expose ComfyUI directly.
- This is not a signed desktop installer or a managed multi-tenant SaaS release.

## Release evidence

- `pnpm gate:release`: 154 unit/integration checks and 18 production Chromium journeys passed.
- 500-node production board: 584 ms load, 17.5 ms animation-frame p95 in the release run.
- Web budget: 879.0 KiB initial resources, 257.0 KiB CSS; the Three.js scene remains an async chunk.
- `pnpm audit --prod --audit-level high`: no known production dependency vulnerabilities.
