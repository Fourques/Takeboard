## 这一版更新了什么

- 明确区分项目保存位置与生成服务：项目可留在本机，连接远程 ComfyUI 生成；需要使用服务器项目时，仍可显式连接远程 TakeBoard。
- 改善设备连接、原生文件夹操作及生成结果回收的边界，减少本机与远程位置混淆。
- 统一节点、连线、右键菜单和右侧详情的选择状态；后台响应不再抢回刚取消或切换的镜头。
- 镜头草稿按工作流隔离，切换镜头不会把尺寸等参数写入另一个工作流；素材输入始终依据真实连线。
- 提交中停止会等待任务确认，只取消对应镜头，并停止继续提交剩余候选；离开项目不会擅自取消已接受的任务。
- 新提交和重开的任务使用同一恢复逻辑；候选批次按已保存结果显示进度，重试不会重复计数。
- 清理重复画布写接口、废弃包和个人脚本，保留命令确认、权限、版本冲突、操作记录与撤销保护。外部旧 API 调用需按[迁移说明](https://github.com/Fourques/Takeboard/blob/v0.2.0-beta.4/docs/canvas-api-migration.md)更新。

## 升级与 Mac 测试

先备份重要项目，等待本机任务结束，完全退出旧 TakeBoard。打开 DMG，将 TakeBoard 拖入“应用程序”并替换旧 App，再从“应用程序”打开。不要删除 `TakeBoardData` 或外部项目目录。

`beta.3` 用户可在桌面更新窗口选择测试版频道后检查更新；也可直接下载本页安装包。更新不会自动安装，不会替远程服务升级。连接旧版远程 TakeBoard 时使用的是远端页面和服务，需要服务器所有者单独升级才能测试全部新逻辑。

建议依次检查：原项目重开、默认保存位置、生成服务连接、切换镜头后的输入保留、生成与停止、结果播放及下载、删除和撤销。先用测试项目，不直接覆盖重要作品。

## 预览版边界

- macOS 使用临时签名，尚无 Apple notarization；Windows 尚无商业代码签名。若系统提示未知开发者，请确认是本仓库的下载，再通过系统针对该应用的允许打开入口处理，不要全局关闭系统防护。
- 不附带 ComfyUI、模型或自定义节点。自动化任务测试不等于真实 GPU 生成质量或所有工作流兼容性验证。
- Linux DEB 面向 Debian/Ubuntu；GLib 上游间接依赖的已公开限期例外未被本次版本消除。
- 校验文件及构建来源证明保留在 Actions。GitHub 自动提供的 Source code 是开发者源码，不是安装包。
