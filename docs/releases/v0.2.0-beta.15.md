# TakeBoard v0.2.0-beta.15

Mac M 系列设备连接修复版。

- 修复免登录使用设备设置时，登录弹窗反复出现的问题。
- 在生成设备设置中直接展示启动 ComfyUI 和释放空闲显存的操作。
- 启动失败明确显示错误，不再误报连接成功。
- SSH 设备可配置远程 Linux systemd 用户服务，启动前检查资源，连接失败仅回滚确认属于本次启动的服务。
- 不再默认使用开发测试机的服务名。

## 使用与限制

安装包为 Apple Silicon（M 系列）`.dmg`。安装更新后生效，不会自动替换服务器上的 TakeBoard。
远程启动当前适配已配置的 Linux 用户服务及单卡 NVIDIA 设备；其他远端可连接已运行的 ComfyUI 并释放空闲显存，但暂不支持通用自动启动。SSH 共享远端服务不会随本机退出自动停止。

源码完整验证及 12 项浏览器回归已通过；远程启动安全分支使用模拟测试，不代表所有远端安装方式均已实机验证。发布流水线另行验证最终 DMG 内的运行时。
本测试版未进行 Apple notarization。
