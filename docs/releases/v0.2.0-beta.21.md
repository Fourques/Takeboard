# TakeBoard v0.2.0-beta.21

改进工作流校验、结果比较与参数沿用，并修复远程连接变化后的空闲资源清理。

## 本版更新

- 同类生成结果可并排查看。沿用历史提示词与参数时，只更新当前草稿，不自动生成、替换素材连线或改变采用状态。
- 推荐模板执行前核对实际内容；修改过的模板可通过可编辑副本继续配置，避免界面中的工作流与实际执行不一致。
- 工作流错误保留明确的恢复入口，不在网络异常后自动重新提交生成。画布参数按工作流能力显示，Wan 预览固定四步。
- 中文输入法组合输入不再触发画布快捷键或数字输入确认；画布投影复用索引，保留用户素材文件名。
- 空闲模型卸载核对当前连接身份，重连或端口复用后不再使用旧客户端释放资源。
- 独立 AutoDL 适配器提供工作流初始化、模型校验和可恢复验收。补齐跨平台路径检查，下载及验收脚本使用进程锁，防止崩溃恢复或并发运行造成重复操作。此更新不会自动替换已保存的云端镜像。

## 下载与升级

Mac 使用 DMG，Windows 使用 EXE，Debian/Ubuntu 使用 DEB。每个平台均提供 x64 与 ARM64；Apple 芯片选择 `aarch64.dmg`。

先备份重要项目，退出旧版后安装新版，无需删除项目目录。安装包不包含 ComfyUI、模型或第三方节点。远程 TakeBoard 与自托管 Portal 需要分别更新；本机升级不会修改远程服务或 AutoDL 镜像。

## 验证与限制

发布流程对最终 DMG 挂载、EXE 与 DEB 安装后的包内运行时执行检查，并校验安装包 SHA-256。具体结果以本版 GitHub Actions 记录为准；不将构建与运行时检查当作所有平台的原生 UI 或 GPU 生成验收。

本版仍为预览版：macOS 未完成 Apple notarization，Windows 未使用商业代码签名。Linux GTK3 依赖链仍有已记录的上游警告及限时例外，见[安全政策](https://github.com/Fourques/Takeboard/blob/main/SECURITY.md)。

## English

Compare available results side by side and reuse recorded prompts and parameters in the current draft without generating again or changing connections and adoption. Maintained templates are checked against their actual execution graph, and workflow failures lead to explicit recovery actions rather than automatic resubmission.

This release also fixes IME shortcut handling, hides unsupported generation controls, improves canvas projection and ties idle model unloading to the current connection. The independent AutoDL adapter adds checked starter workflows and crash-safe maintenance scripts; it does not update an existing cloud image.

Back up important projects, close the old app and install the package for your OS and CPU. ComfyUI and models are not bundled. Remote deployments must be updated separately. These are preview installers, not Apple-notarized or commercially signed on Windows; packaged-runtime checks are not a claim of new GPU validation on every platform.
