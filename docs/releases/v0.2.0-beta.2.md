选择你的电脑，只下载一个安装包。无需安装 Node.js、pnpm 或 Rust。
Choose your computer and download one installer. No developer tools required.

- **Mac**：打开 DMG，将 TakeBoard 拖入“应用程序”，然后从应用程序打开。
- **Windows**：运行安装程序，再从开始菜单打开 TakeBoard。
- **Debian / Ubuntu**：用系统软件安装器打开 DEB，安装后从应用菜单启动；不适用于所有 Linux 发行版。

Mac: open the DMG and drag TakeBoard into Applications. Windows: run the installer, then launch from
Start. Debian/Ubuntu: install the DEB using your software installer and launch from the applications menu.

> Preview: not Apple-notarized or commercially Windows-code-signed. Your OS may warn or block it.
> Do not disable system-wide protections. ComfyUI and models are required separately for generation.

## 本次更新 / Highlights

- 原生应用封装，自动启动本机服务，不再要求管理解压目录或运行脚本。
- 本机默认免注册；登录可选，账号项目仍受权限保护，支持保持登录。
- 桌面“连接 → 连接设备…”提供标准 SSH、HTTPS 和自托管 Portal 入口与最近连接。
- 连接验证实际服务身份，关闭远程窗口只清理自己建立的连接，不停止远端生成。
- 修复高密度显示、登录恢复和远程窗口权限问题，更新图像解码与测试依赖安全修复。

Native app packaging, optional local login, remembered sessions, verified remote connections,
high-density display fixes and dependency security updates. The Portal is self-hosted, not an operated public cloud.

## 数据与验证 / Data and verification

项目默认位于 `~/TakeBoardData`，不在应用安装目录内。升级前导出重要项目并备份完整数据目录；
不要让新旧实例同时写同一目录，回退请使用升级前备份。

Projects stay in `~/TakeBoardData`, outside the app. Back up before upgrading. Never run old and new
instances against the same data directory simultaneously; use a pre-upgrade backup for rollback.

各平台安装包须通过打包后运行时启动、创建项目、重启保留数据及退出清理检查后才发布。
这些自动检查不等于所有系统版本、GPU 和工作流的完整人工验收，也不替代操作系统签名。
校验与构建来源证明保留在流水线中，不需要另行下载校验文件。

Packages are checked for runtime startup, project creation, restart persistence and cleanup. These
automated checks are not exhaustive native UI/GPU compatibility or OS signing certification.

底部 **Source code** 是开发者源码，不是安装包。历史便携包停止分发。
**Source code** archives are for developers, not installers. Portable downloads are retired.
