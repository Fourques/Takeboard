# TakeBoard v0.2.0-beta.5 · Mac M 系列调试版

[下载 Mac M 系列安装包（DMG）](https://github.com/Fourques/Takeboard/releases/download/v0.2.0-beta.5/TakeBoard-v0.2.0-beta.5-macos-arm64.dmg)

本次只提供 Apple Silicon（M 系列）版本，用于首页与连接体验调试。Intel Mac、Windows 和 Linux 继续使用 beta.4；本次没有为它们发布安装包。

## 本次更新

- 首页保留 3D 导演板和四个互动元素；运行中心只显示生成任务与简洁的存储概览。
- 诊断移到设置，点击后才检测；设备快捷列表与连接配置分开，SSH、服务控制与调度偏好统一在设置中管理。
- 不把回环地址误认为本机 GPU，未检测的 SSH 设备不假报在线；连接验证失败不切换原设备。
- 设置按外观、项目与存储、设备连接、运行诊断、关于与更新分组，改善窄窗口和大字体布局。
- 登录入口改为账号图标，修复登录与 Aa 弹窗；远程连接及更新窗口跟随当前主题。
- 更新桌面使用帮助，明确“导入项目包”恢复的是 TakeBoard 导出的 `.takeboard.tgz`，普通图片、视频在画布或资产库导入。

## 安装与测试

构建源码为 `fa1779e1311404eae7fc6c2b68d4d409060a9f7e`。[Apple Silicon 构建记录](https://github.com/Fourques/Takeboard/actions/runs/34551413471)中的 DMG 挂载、包内运行时验证、来源证明与产物上传均通过。本地完整质量门禁与 44 项浏览器回归通过，GitHub 同一提交的 macOS 代码检查通过；不将这些结果称为用户 Mac 上的人工体验验收。

备份重要项目，等待本机任务结束并完全退出旧 TakeBoard。打开 DMG，将 TakeBoard 拖入“应用程序”并替换旧 App，再从“应用程序”打开。不要删除项目目录或 TakeBoardData。

建议先检查：首页运行中心、设备选择、设置分类、Aa 大字体、可选登录、远程连接窗口主题，以及原项目重开。连接远程 TakeBoard 时显示的是远端页面；只升级本机 App 不会升级远端服务。

本版仍是临时签名的调试包，尚无 Apple notarization。请确认下载来源，通过系统针对该应用的允许打开入口处理提示，不要全局关闭 Gatekeeper。安装包不包含 ComfyUI、模型或自定义节点。

校验文件和来源证明保留在 Actions，不额外放到下载附件中。GitHub 自动提供的 Source code 是源码，不是安装包。原生构建与包内服务验证不等于 Mac 窗口人工验收或真实 GPU 工作流验证。
