# TakeBoard AutoDL 云版

基于 ComfyUI 的开源创作画布。在同一个项目中连接素材、提示词和生成结果，制作图片与视频。

此目录只提供独立的云端部署配置，不改变桌面版的默认设置。当前镜像使用 TakeBoard 0.2.0-beta.20，预装 SDXL Base 1.0 和 Wan 2.1 T2V 1.3B 两份原生节点工作流。模型已下载，无需首次开机重新下载。

这是已制作镜像的启动适配与维护脚本，不是空白 Linux 的完整安装器，也不包含 Docker 镜像构建。此目录随源码更新，不会自动升级 AutoDL 中已保存的镜像；平台审核通过、新实例冷启动验收与源码测试是三个不同的状态。

## 开始使用

在实例终端运行以下命令并保持终端开启。仅启动 TakeBoard，ComfyUI 在需要时从 TakeBoard 中安全启动。

```sh
/opt/takeboard/node-v24.21.0-linux-x64/bin/node /opt/takeboard/autodl/start.mjs /opt/takeboard/cloud.json
```

在自己的电脑另开一个终端，使用 AutoDL 控制台提供的 SSH 地址和端口建立转发：

```sh
ssh -N -L 48230:127.0.0.1:48120 -p <SSH端口> root@<SSH地址>
```

打开 <http://127.0.0.1:48230>，首次使用设置自己的管理员账号。新建项目，在设备连接中启动生成服务，然后选择 SDXL 图片或 Wan 视频工作流。不要与他人共用账号或 SSH 凭据。

初始入口只通过 SSH 访问，不开放无人认领的管理员注册。需要平台 HTTPS 入口时，先完成上述账号初始化，再将独立配置中的 `mode` 改为 `https`，`port` 设为平台分配端口，`publicUrl` 填入平台给出的完整 HTTPS 根地址。配置示例见 [cloud.example.json](cloud.example.json)。不能填通配符或猜测访问域名。

## 项目与资源

项目、身份、上传素材与生成文件位于 `/root/autodl-tmp/TakeBoard`。程序和预装模型位于 `/opt/takeboard`，源码位于镜像中的 `/root/TakeBoard`。保存系统镜像不包含数据盘中的项目；克隆或更换实例前，请单独备份项目与结果。

生成完成后，TakeBoard 会在空闲时卸载模型；也可以在生成服务菜单中主动释放资源或停止受管理服务。忙碌时不会强制中断其他任务。关闭浏览器、释放显存或停止 ComfyUI 都不等于 AutoDL 实例关机。用完请备份项目，并在控制台关机；费用与磁盘保留规则以平台为准。

## 预装工作流

| 工作流 | 默认参数 | 模型许可 |
| --- | --- | --- |
| SDXL 图片 | 1024 × 1024，25 步 | CreativeML Open RAIL++-M |
| Wan 2.1 视频 | 832 × 480，5 秒，16 fps，25 步 | Apache 2.0 |

两份工作流使用固定版本的 ComfyUI 原生节点，默认不加载第三方自定义节点。模型来源、固定版本、完整哈希及许可链接见 [models.json](models.json)。使用模型和输出时仍需遵守其许可与平台规则。

在制作实例上已完成真实图片、视频生成、下载校验、视频完整解码、任务取消、空闲显存释放、受管理服务停止重连和 TakeBoard 重启持久化检查。首次空数据启动也已检查；从最终保存镜像创建新实例的冷启动属于单独的发布检查，不能用前述结果替代。

## 发布维护

`start.mjs` 提供私有默认入口和可选 HTTPS 配置；`seed-workflows.mjs` 仅首次安装已验收的工作流，不覆盖用户修改。`download-models.mjs` 校验固定模型版本与 SHA-256。`acceptance.mjs`、`lifecycle.mjs` 和 `check-first-boot.mjs` 用于维护者实机验收，不是用户启动命令；前两者会提交真实任务，不能在正在创作的实例上随意运行。

下载器面向 Linux，需安装 util-linux 的 `flock`。`.takeboard-download.flock` 是可复用的内核锁文件，不应删除；下载子进程继承锁，主进程异常退出时仍不会开启第二个下载者。若遇到旧版 `.takeboard-download.lock`，先核对下载进程与日志，确认旧下载者已经退出后再移除旧锁，不能只看锁文件日期。

生成验收与生命周期验收共用进程锁，不允许同时运行。在提交前保存意图；网络中断后重跑，会恢复已记录的任务，或按镜头、工作流和种子核对丢失的回执。找不到或找到多个可能任务时停止并保留现场，不自动重新生成；请先检查私密数据目录中的任务记录和服务日志。内核锁文件不应删除，进程退出后会自动释放。

公共镜像不得包含账号、会话、SSH 私钥、项目、生成记录或验收凭据。平台审核回执与镜像保存结果分别记录，代码或生成验收通过不代表已上架。
